# Problem Statement

## 1. Title
Job Portal with Employer Dashboard.

## 2. Domain

Human Resource Management (HRM) / Recruitment Technology (HRTech) / Web Application Development.

## 3. Who is the User?

### Candidate
- Register & Login
- Create Profile
- Upload Resume
- Apply for Jobs

### Employer
- Register Company
- Post Jobs
- View Applications
- Shortlist Candidates

### Admin
- Manage Users
- Verify Employers
- Monitor Platform

## 4. What Problem are we Solving?
Many companies receive thousands of job applications, making manual resume screening slow and inefficient. Existing job portals also face security challenges such as unauthorized access, fake employer accounts and data breaches. This project aims to develop an AI-Powered Secure Job Portal with Employer Dashboard that automatically ranks candidates based on their skills and resumes while protecting hiring workflows, securing employer dashboards and preventing unauthorized access using modern cybersecurity practices.

## 5. Proposed Solution
Develop a secure full-stack Job Portal where employers can post jobs and candidates can apply online. The system uses AI to rank candidates based on skills and resumes. It also provides secure authentication, role-based access control, password encryption, secure resume uploads and protected employer dashboards.
